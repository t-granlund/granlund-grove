## The Through-Line

Across every role, the same philosophy shows up: **understand what people need,
then remove the technological obstacles that make their day-to-day harder.**
Technology should serve people, not the other way around. Support the people
behind the counter, make their work less stressful, and you create brand
ambassadors. It started at Apple with a 1-to-many support philosophy — *teach
the room, not just the person* — and it still drives how Tyler builds today.

## Signature Projects

### Control Tower
Multi-tenant governance platform for cost, identity, and compliance across the
whole estate. Built with Python 3.12 / FastAPI + Pydantic v2 + SQLAlchemy +
PostgreSQL 16, HTMX + Alpine.js + Tailwind frontend, on Azure App Service / Key
Vault / Storage, deployed via GitHub Actions with OIDC. Server-rendered HTMX was
chosen over a SPA to keep the attack surface small and auditable.
- **7,386 automated tests** (pytest unit, Playwright E2E, axe-core a11y,
  architecture-fitness) and a **48/48 automated judge score** gate every release.
- v2.5.0 in production (June 2026), all five tenants syncing live. Architecture
  and guardrails being open-sourced.

### Knowledge Fabric
Identity-aware RAG system that answers from **100K+ Freshdesk support tickets**,
scoped to who's asking. Multi-agent ingestion pipeline (extractor → transformer →
embedder → indexer) over SQLite + FTS5, with Entra identity as the grounding
layer.
- **1,523 verified humans** across a **15-slot attribute schema**.
- Phase 1 closed at **52/52 QA checks**. Identity-aware patterns being
  open-sourced as part of TenantFleet.

### Estate Trace
Answers "what do we run and what does it cost" across **41 repos**, **11
subscriptions**, and **~196 Azure resources**. Live read-only pulls against
version control, identity, cloud cost management, invoices, and licensing APIs,
feeding a DuckDB analytical warehouse.
- **12/12 verification checks** gate every refresh.
- Surfaced a ~$12.2K/mo IT/Technology run-rate and a conservative ~40%
  optimization path. Shipped to production to inform executive cost decisions.

### Zero-Secret Automation
Full lifecycle automation (onboarding, offboarding, leave-of-absence) across
**five tenants without storing a single credential**. GitHub Actions with
workload identity federation per tenant, driven from Monday.com webhooks and CSV
inputs. Every run leaves a least-privilege audit trail. Onboarding: days →
minutes. Offboarding: immediate and auditable.

### Mysa Mail _(personal)_
Local-first AI email agent that asks before it acts. FastAPI + SvelteKit,
**5,700+ LOC backend**, **5 classifiers** (urgent, follow-up, newsletter, social,
spam), approval workflows before any destructive write. Local Ollama by default,
cloud opt-in. **WCAG 2.2 AA** throughout. Shipped and in daily use.

### TenantFleet Ecosystem _(open source)_
Seven MIT-licensed repos for multi-tenant Microsoft Entra ID governance, built
for MSPs, PE firms, and multi-brand portfolios:
1. **TenantFleet** — root governance framework
2. **HubForge** — Static Web App templates
3. **EntraGroups** — Microsoft 365 group lifecycle
4. **TenantForge** — Terraform tenant provisioning
5. **DNSGuard** — domain security monitoring
6. **RampGuard** — finance compliance & expense governance
7. **SharePointAgent** — document indexing & search

### Code Puppy _(build environment)_
The supervised multi-agent system Tyler builds production software with — planner,
programmer, code-reviewer, and security-auditor agents with human-in-the-loop
approvals before any destructive write, every release gated by automated tests
and judge scores. Open-source project created by Michael Pfaffenberger and John
Choi; it won Walmart's **President's Innovation Award** and is used by 4,000+
Walmart employees. Tyler is a contributor.
